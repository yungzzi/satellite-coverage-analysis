# ATK 引擎集成收口总结（2026-08-18）

> 本文是 ATK 二次开发这条线的阶段性收口记录。结论：**对我们项目需求范围内的功能，ATK 集成已基本完成**；
> 剩余受限项多属 ATK 4.0.1-rc.5 版本缺陷，已记录待官方修复（给官方的反馈邮件已发、暂未回复，**反馈材料暂缓整理**）。

## 一、定位

ATK 是覆盖计算的**可选引擎**（与自研几何引擎并列）：自研为默认（快速、免依赖），
ATK 用于复杂传感器场景。两引擎输出格式一致，覆盖分析与选星流程共用。

## 二、已实现并验证

### 传感器类型（5 种）
- SimpleCone / Rectangular / Conical / HalfPower / SAR（SAR、HalfPower 走 XML 双实例路线）

### 传感器指向（6 类）
- 天底（默认）、Fixed（YPR/欧拉/四元数/AzEl/矩阵）、入射高度、外部指向文件、
  Targeted（追踪/固定偏置）、Spinning 旋转（单实例方案：同实例内可复现）

### 约束（基本 + 光照）
- 基本：方位角、仰角、距离、三种变化率、角变化率、高度、传播延时、视线、视场、地形
- 光照：太阳/月球仰角、视线/视轴太阳/月球规避角
- 界面为 ATK 同款“开关 + 输入框”布局，默认折叠，逐条参数说明

### 区域覆盖定义
- 网格化区域覆盖率输出，与自研引擎逐分钟 100% 对拍（480/480）

### 逐星配置与整星姿态
- 每颗星独立配置类型/参数/指向/约束；逐星覆盖全局
- 整星标准姿态族（AttGenType 0-4 + 偏移四元数，XML 注入，已验证生效）：
  固连系VVLH / 惯性系VVLH / ECI对速度定向 / ECF对速度定向 / 太阳对齐

### 工程化
- 真正无头（隐藏桌面）、并行调度（旋转星单实例+普通星并行 A/B 模式）
- 配置持久化（TOML：全局/逐星）、GUI+CLI 双入口

## 三、已知限制

### rc.5 版本缺陷类（待官方修复）
- Spinning 传感器相位跨实例不锚定 → 已用“单实例”缓解（同实例内可复现）
- SAR“跟踪父高度”开关经 XML 加载/内存 Define 均不生效 → 已用各星 TLE 平均轨道高度近似
- 整星非标准姿态（固定/旋转/目标指向）：Legacy 姿态体系不序列化、不生效（无 ground truth，
  已定案 §10.34）→ 需求由传感器级指向承担
- Connect 命令层缺失：SAR Define 静默失效、Targeted/姿态命令 NACK → 已走 XML 注入

### 需求范围外（非“未实现”）
- 时间约束：软件输入时段本身即时间约束，不需要 ATK 侧实现
- 多边形目标：自研引擎支持；ATK 引擎只做点+半径（≤5 km 圆）
- 通信约束：仅适用发射/接收器对象，项目不涉及

## 四、结论与后续

- **ATK 集成收口**：当前需求范围内可挖的功能已全部实现并验证；再往下主要是等官方修复/新版本。
- **升级成本低**：XML 注入、单实例、逐星配置等机制已搭好，ATK 修复后把被卡开关接上即可。
- **重心回归自研**：覆盖计算默认自研，选星算法（整数规划/贪心/最优枚举）、验证体系、工程交付继续推进。
- **反馈暂缓**：给 ATK 官方的邮件已发（Spinning 相位等），暂未收到回复，反馈材料整理暂停，等有回复再继续。
