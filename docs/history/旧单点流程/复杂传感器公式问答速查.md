# 复杂传感器公式问答速查

> 你不是要"会推公式"，是要"被问到能接住"。下面每个公式给你三行：**是什么、在干嘛、被问怎么说**。
> 核心一句：**公式是程序怎么算，原理靠"ATK 对拍 + 数值自检"兜底。**

---

## 最可能被问的 6 个公式

### 1. 姿态（机身朝向）

| | |
| --- | --- |
| 长这样 | $\hat{\mathbf{z}}=-\hat{\mathbf{r}}$，$\hat{\mathbf{x}}=\frac{\mathbf{v}-(\mathbf{v}\cdot\hat{\mathbf{z}})\hat{\mathbf{z}}}{\lvert \cdot \rvert}$，$\hat{\mathbf{y}}=\hat{\mathbf{z}}\times\hat{\mathbf{x}}$ |
| 在干嘛 | 用卫星位置 $\mathbf{r}$ 和速度 $\mathbf{v}$ 拼出"机身三个轴分别朝哪"：$\hat{\mathbf{z}}$ 朝地心（正下方），$\hat{\mathbf{x}}$ 朝飞行方向，$\hat{\mathbf{y}}$ 补右手系 |
| 被问怎么说 | "机身朝向由位置和速度定下来——正下方 + 飞行方向，再叠加用户给的侧摆角度。这个三轴是后面所有镜头方向的基准。" |

### 2. 覆盖判定（目标进没进镜头）

| | |
| --- | --- |
| 长这样 | $\hat{\mathbf{u}}_s\cdot\hat{\mathbf{z}}_s\ge\cos\eta$（目标方向与镜头正对方向的夹角 ≤ 视场半角） |
| 在干嘛 | 算"目标相对镜头"与"镜头正对方向"的夹角，够小就算覆盖 |
| 被问怎么说 | "本质是算夹角——目标方向和镜头正对方向的夹角小于镜头半角就覆盖。旧版只能朝正下方，所以夹角是相对正下方；现在镜头能偏能转，就先把'镜头朝哪'也算进去。" |

### 3. 半功率波束（雷达/通信）

| | |
| --- | --- |
| 长这样 | $\eta = 35\,\lambda / D$（半角 = 35 × 波长 ÷ 天线直径），$\lambda=c/f$ |
| 在干嘛 | 由频率 $f$ 和天线直径 $D$ 算出天线波束的半宽 |
| 被问怎么说 | "这是天线学标准公式 $\mathrm{HPBW}\approx70\lambda/D$，半角取一半。频率和直径给了就出波束宽度，有教科书出处（Balanis《Antenna Theory》）。" |

### 4. SAR 条带

| | |
| --- | --- |
| 长这样 | $\varepsilon_{\min}^{\mathrm{SAR}}\le\varepsilon_{\mathrm{ground}}(P)\le\varepsilon_{\max}^{\mathrm{SAR}}$，且前后排除角 $\ge\psi_f,\psi_a$ |
| 在干嘛 | 只能照"入射仰角在一个区间、且不在正前正后方"的地面条带 |
| 被问怎么说 | "SAR 是侧视雷达，只能照仰角带里的窄条带，且排除正前/正后方。这是 STK 官方对 SAR 传感器的定义（IAgSnSARPattern）。" |

### 5. 旋转扫描

| | |
| --- | --- |
| 长这样 | $\psi(t)=\varphi_0+\omega(t-t_0)$（转过的角度随时间线性增） |
| 在干嘛 | 镜头绕固定轴匀速转圈扫，每个时刻角度由起点角 $\varphi_0$ 和转速 $\omega$ 算 |
| 被问怎么说 | "像个泛光灯匀速转。我们把起始角度写死成分析起点对应的值，所以同参数每次结果一样——这比 ATK 更确定（ATK 起始相位随机）。" |

### 6. 入射高度（切球）

| | |
| --- | --- |
| 长这样 | $\sin\beta=a/r_s$（$a=R+H$），即视轴与"离地 $H$ 的球面"相切 |
| 在干嘛 | 镜头贴着某高度的大气边缘看 |
| 被问怎么说 | "用'视线和离地某高度球面相切'来定义，比直接给仰角更贴临边观测。我验证过视线到地心距离确实等于球半径。" |

## 被问到不会的公式，三步接住

1. **先讲它在干嘛**：用上面"在干嘛"那一句，把话题从"怎么推"拉到"做什么"。
2. **再报出处**：`这个公式用的是 XXX 标准定义（STK/天线教材/天文历表），不是我编的。`
3. **重点是兜底**：`我没手推它，是用它写程序 + 用 ATK 对拍（四种误差 3% 以内）+ 数值自检 135 项确认的。所以更该问的是"怎么验证"，而不是"怎么推导"。`

---

## 终极心理建设

> **公式是"程序怎么算"，不是"你要汇报什么"。** 你汇报的是：做了个更真实的卫星相机模型（姿态 + 指向 + 视场），并用专业软件 ATK 对照过、旧版功能没动、旋转扫描还比 ATK 更确定。
>
> 真被问到公式推导，就诚实说"这块是标准定义，我交给代码和验证兜底了"，然后自然把话题引到你最熟的"三件事 + 五层验证"上。**没人指望你背公式**——验证体系存在的意义，就是让"会不会推"不再成为可信度的前提。
