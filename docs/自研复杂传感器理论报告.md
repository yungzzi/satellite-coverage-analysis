> 版本：v1.0　日期：2026-08-19　适用代码：`src/coverage_analysis.py` 的扩展（规划中：`src/sensor_geometry.py`、`src/attitude_geometry.py`）
> 目标：把 ATK 侧已实现并验证的全部传感器类型（5 种）、指向（6 类）、整星姿态族（5 个）、约束（基本 12 + 光照 7）用**解析几何**在自研引擎中实现，输出口径不变（覆盖窗口），全部**确定、可复现**。

## 摘要

自研引擎当前的覆盖模型是"**天底固定圆锥 + 最小仰角**"（视场半角 η = 视线张角，默认 10°）。要覆盖 ATK 的全部能力，需要回答三个问题：

1. **姿态**：卫星本体在空间怎么指向（对地、对速度、对太阳、固定、旋转、凝视）？
2. **传感器指向**：视轴相对星体怎么偏（侧摆固定角、切球入射、追目标、旋转扫描、外部文件）？
3. **视场形状**：视轴周围多大的立体角算"看得见"（圆锥、矩形、内外锥+钟角、半功率波束、SAR 条带）？

本报告给出完整数学方案，核心思想只有一句话：

> **覆盖判定 = 把目标方向矢量变换到传感器坐标系，再做一组"视场不等式"检查。**

所有量（位置、速度、姿态、视轴、目标方向、太阳/月球方向）都是时刻的解析函数，因此整个计算链路是**确定性**的——这比 ATK 的 Spinning 跨实例相位不锚定（版本缺陷，§10.18）更可靠。ATK 已有实测数据（SimpleCone45 对拍：ATK 69 窗口 vs 自研 70、匹配 69；Conical 退化一致；Rectangular 74 窗口；SAR 6 窗口；HalfPower 5 窗口；姿态族 0 vs 4 端到端差异；Targeted GUI 91.282 s 窗口）全部可作为对拍基准（8.3 节）。

# 第 1 章　坐标系与姿态表示基础

## 1.1 需要的坐标系

| 坐标系 | 说明 | 用途 |
| --- | --- | --- |
| ECI（TEME） | SGP4 直接输出的惯性系（近真赤道/平春分点系） | 轨道外推、惯性姿态（P1/P2/P4） |
| ECEF（ITRS） | 随地球自转的地固系 | 星下点、目标坐标、ECF 姿态（P0/P3）、方位/仰角 |
| 轨道局部系（VVLH/LVLH） | 随卫星轨道运动的本地系 | 姿态基准、传感器本地角定义 |
| 体坐标系（Body） | 卫星本体 | 传感器安装、姿态偏移 |
| 传感器坐标系（Sensor） | 以传感器为原点、视轴为 +z | 视场不等式判定 |
| ENU（站心/表面局部系） | 目标点或卫星处的北-东-天 | 地面仰角/方位角、太阳仰角 |

坐标系间关系：

```
ECI(TEME) ──GMST/章动/极移──▶ ECEF(ITRS) ──本地子午线──▶ ENU(目标点/卫星)
    │                                │
    └───────── VVLH 轨道系 ──────────┘
                    │
                 体坐标系（姿态族/偏移四元数）
                    │
                 传感器坐标系（指向 → 视轴）
```

**TEME → ECEF**：工程上取

　　r_ECEF = R₃(GMST) · r_TEME　　　　(1.1)

其中 R₃ 为绕 Z 轴旋转，GMST 为格林尼治平恒星时。真实链路还包括章动（真赤道）与极移，但对覆盖判定的影响在弧秒级（地面 ~100 m、窗口亚秒级），远小于 TLE 时效误差（公里级），本报告采用 GMST-only 约定，与 skyfield `subpoint()` 的口径差异已在现有报告中量化（仰角 1° 级、边界分钟翻转仅在恰好压线 10.0° 时出现）。

**ECEF 速度**：由 ECI 速度扣除地球自转牵连速度：

　　v_ECEF = v_ECI − ω_⊕ × r_ECEF　　　　(1.2)

这是 P0/P3 姿态族（"固连系速度"）所需。

## 1.2 旋转矩阵与四元数

旋转矩阵 C 满足 CᵀC = I、det C = +1。**约定**：C 的列是"新系基向量在旧系中的坐标"，即对列向量 v：v_new = C·v_old。

**四元数** q = (qs, qx, qy, qz)，|q| = 1，旋转向量 v：

　　v′ = v + 2·qs·(q_v × v) + 2·q_v × (q_v × v)　　　　(1.3)

其中 q_v = (qx, qy, qz)。四元数复合（先 q₁ 后 q₂）：

　　q = q₂ ⊗ q₁　　　　(1.4)

复合公式（标准 Hamilton 积）：

　　(qs, q_v) ⊗ (ps, p_v) = (qs·ps − q_v·p_v,  qs·p_v + ps·q_v + q_v × p_v)

**欧拉角/YPR → DCM**：ATK 的转序（Euler：121/123/…/323；YPR：YPR/YRP/…/RPY）按**本体连续旋转（intrinsic）**约定：

　　R(seq="123", r1, r2, r3) = R₃(r3)·R₂(r2)·R₁(r1)　　　　(1.5)

　　R(YPR 序) = R_roll·R_pitch·R_yaw（按序左乘）　　　　(1.6)

其中 R₁/R₂/R₃ 为绕 x/y/z 的基本旋转矩阵。**注意**：欧拉/YPR 的正负号与内外旋约定需与 ATK 输出对拍校准（8.3 节），报告中所有公式采用上述显式约定，一旦实测偏差即翻转对应项。

## 1.3 从 SGP4 到 r、v，以及太阳/月球方向

现有引擎已通过 skyfield 的 `EarthSatellite.at(t)` 获得卫星 TEME 位置与速度（`geocentric.position.km` / `.velocity.km_per_s`），并由 `subpoint()` 得到星下点经纬高。扩展后还需要：

- TEME 位置速度 r_TEME, v_TEME（已可得）；
- ECEF 位置 r_ECEF 与速度 v_ECEF（由 (1.1)(1.2)）；
- 太阳/月球地心方向 ŝ(t)、m̂(t)（P4 姿态与光照约束用）。

**太阳/月球方向**：生产实现用 skyfield 的 `load('de421.bsp')`（项目已有依赖，离线缓存后可复用）；无星历时可用 Meeus《Astronomical Algorithms》第 25 章低精度解析公式（太阳标称 ~0.01°、本机用 DE430 测试子集对拍 0.21°；月球 ~0.3°）。光照约束（昼夜判断、规避角）对 0.5° 级误差不敏感。

# 第 2 章　卫星姿态：必要性分析与构造公式

## 2.1 姿态为什么决定覆盖

传感器视轴在惯性空间的方向由**两级旋转**决定：

　　视轴(ECI) = C_body←ECI · b_sensor(body)　　　　(2.1)

其中 C_body←ECI 由整星姿态决定，b_sensor 由传感器指向（第 3 章）决定。覆盖判定最终检查目标方向是否落在视轴周围的视场立体角内。因此**姿态不参与"目标是否在地球上"这类粗判，但决定视轴指向哪里、足印落在哪里**——侧摆、凝视、扫描、SAR 侧视都依赖姿态/指向的精确建模。

## 2.2 必要的姿态全集（与 ATK EVeProfile 0-4 对齐）

ATK 的整星标准姿态族（`ICEnum.h` 枚举 `EVeProfile`，用户 GUI 保存场景为 ground truth，§10.33）：

| 编号 | ATK 名称 | 物理语义 | 典型用途 |
| --- | --- | --- | --- |
| 0 | 固连系VVLH（对天底定向 + 固连系速度约束） | Z 轴对地心，X 轴尽量沿 ECF 速度 | 默认对地遥感（大多数低轨成像/测绘） |
| 1 | 惯性系VVLH（对天底定向 + 惯性系速度约束） | Z 轴对地心，X 轴尽量沿 ECI 速度 | 对地遥感另一常见约定（差异仅在 X 轴绕天底的滚转） |
| 2 | ECI 对速度定向（+ 天底约束） | X 轴对 ECI 速度，Z 轴尽量对地 | SAR 沿迹向、姿态机动、对地 + 速度复合 |
| 3 | ECF 对速度定向（+ 天底约束） | X 轴对 ECF 速度，Z 轴尽量对地 | 地面轨迹扫描、沿地速方向凝视 |
| 4 | 太阳对齐（+ 天底约束） | X 轴对太阳，Z 轴尽量对地 | 能源/热控优先任务、太阳同步轨道对日定向 |

ATK GUI 中还有**固定姿态**（相对参考轴固定，四元数）、**旋转姿态**（绕固定轴旋转，参考历元+角速度+初始偏移角）、**目标指向姿态**（整星指向目标，默认 Z 轴对齐）。实验已定案（§10.34）：rc.5 的 Legacy 姿态体系对这三类**不序列化、不生效**（无 ground truth），需求已由传感器级指向（Fixed/Spinning/Targeted，第 3 章）承担。因此自研引擎的**整星姿态只实现标准族 0-4 + 偏移四元数**即可覆盖 ATK 实际生效的全部能力；固定/旋转/凝视姿态需求在传感器指向层实现，物理效果相同且更通用。

**"哪些是必要的"结论**：对覆盖分析而言，最小必要集 = **P0（默认对地）+ 偏移四元数（侧摆）**；完整集 = P0-P4 + 偏移四元数。P2/P3（速度对齐）与 P4（太阳对齐）在"对地遥感"主场景中非默认，但老师要求的"姿态改变后感知范围变大"对应的正是**偏置（侧摆）与凝视/扫描**，这些由传感器指向层承担，P0 基准 + 指向偏置即可表达。

## 2.3 标准姿态族的解析构造

统一记法：r̂ = r/|r|（天底方向为 −r̂），v 为对应速度（P0/P3 用 v_ECEF，P1/P2 用 v_ECI），ŝ 为太阳方向（ECI）。

**P0 / P1（天底定向 + 速度约束）**：

　　ẑ = −r̂

　　x̂ = (v − (v·ẑ)ẑ) / |v − (v·ẑ)ẑ|　　　　(2.2)

　　ŷ = ẑ × x̂

即：Z 轴严格指向地心；X 轴取速度在水平面（⊥ ẑ）上的投影并归一化（圆轨道下就是速度方向；椭圆轨道下速度含径向分量，故"不一定重合"）。Y 轴补成右手系。**注**：x̂ 的退化情形（v 与 ẑ 平行，即速度沿径向）实际不会发生（轨道速度始终近似垂直于径向），代码仍加分母防护。

**P2 / P3（速度定向 + 天底约束）**：

　　x̂ = v̂

　　ẑ = (−r̂ + (r̂·x̂)·x̂) / |−r̂ + (r̂·x̂)·x̂|　　　　(2.3)

　　ŷ = ẑ × x̂

即：X 轴严格沿速度；Z 轴取天底方向在 ⊥x̂ 平面上的投影（"尽量对地"），Y 补右手系。

**P4（太阳对齐 + 天底约束）**：

　　x̂ = ŝ

　　ẑ = (−r̂ + (r̂·x̂)·x̂) / |−r̂ + (r̂·x̂)·x̂|　　　　(2.4)

　　ŷ = ẑ × x̂

**体坐标系 DCM**：三轴为列向量（在参考系 ECI 或 ECEF 中表达）：

　　C_body←ref = [x̂ ŷ ẑ]　　　　(2.5)

若基准在 ECEF（P0/P3）而最终需要 ECI 表达，左乘 (1.1) 的逆变换即可。

## 2.4 偏移四元数（侧摆/固定偏置）

ATK GUI 的"偏移角/偏移四元数"是在基准姿态上叠加的固定旋转。XML 记录 qx、qy、qz，标量 qs 由单位化隐含（§10.33 注明无非零 ground truth，先按"qs = +√(1−|q_v|²)"对待）。最终体姿态：

　　C_final = C(q_off) · C_base　　　　(2.6)

即先取标准族基准姿态，再在体坐标上施加偏移旋转。侧摆（roll/pitch 偏置）即令 q_off 为对应角度旋转。

## 2.5 时间离散与数值注意

- 姿态逐时刻计算（与轨道传播同一时间栅格），不假设姿态恒定；
- 每次叉积后重新归一化；投影公式自动处理速度与天底近平行退化；
- 四元数复合后归一化，避免浮点漂移；
- 太阳对齐 P4 在日食/太阳方向与天底近平行时（实际不会，太阳不会穿过地球背后对准卫星正下方）仍由投影公式保护。

# 第 3 章　传感器指向（Pointing）建模

## 3.1 通用框架

传感器坐标系：原点为传感器安装点，视轴为 +z_s，x_s/y_s 为横向参考（x_s 约定沿参考方向，y_s 补右手系，参考方向取沿迹向或本地东向，与 ATK 对拍后固定）。目标方向在传感器系：

　　û_s = C_s←ECI · û_ECI　　　　(3.1)

其中 û_ECI = (P_target − r_sat)/|·|，C_s←ECI = C_pointing · C_body←ECI（指向在体坐标内定义）。

## 3.2 默认指向：体 +Z（VVLH 下即天底）

ATK 传感器默认固定于星体、视轴沿体 +Z 轴；在标准姿态族 P0（固连系 VVLH，体 Z 对地）下
它等于天底，但姿态改变（如 P4 太阳对齐）时视轴跟随体轴偏转。因此本文约定：

　　b = C_body←ECI · (0, 0, 1)　　　　(3.2)

**与现有引擎的关系**：P0 + 无偏移时 (3.2) 严格等于 b = −r̂（天底），复杂引擎对
“SimpleCone + 天底 + 无姿态/指向/约束”的默认路径直接委托现有 `compute_covered_series`，
保证逐位零回归（含 5 km 目标圆边缘余量与球面口径完全一致）；姿态/指向非默认时走完整
几何（2.1 节：离轴角 θ ≤ η ⇔ 足印内 λ ≤ λ_max，等价性已数值自检）。

## 3.3 Fixed 固定指向

视轴在体坐标（或传感器本地参考系）内固定偏置，五种姿态方法（ATK Connect 语法原文）：

| 方法 | 参数 | 本文约定 |
| --- | --- | --- |
| AzEl | 方位角 Az、高度角 El | 本地 ENU：b = (cos El·cos Az, cos El·sin Az, sin El)；El 向上为正（向下为负，侧视常用负值） |
| Quaternion | q1 q2 q3 q4（qx,qy,qz,qs） | b = q ⊗ 基准视轴 ⊗ q⁻¹（(1.3)） |
| Euler | 转序 + Rot1/2/3 | (1.5) 的 DCM 旋转基准视轴 |
| YPR | 转序 + Yaw/Pitch/Roll | (1.6) 的 DCM 旋转基准视轴 |
| matrix | d11 d21 d22 d31 d32 d33 | 3×3 旋转矩阵的前 6 个元素（重建规则待 ATK 对拍，见 3.8） |

AzEl 的方位参考方向（沿迹向 or 北向）与 El 符号待与 ATK 对拍校准；默认取"Az 相对沿迹向、El 相对本地水平面、向下为负"。

## 3.4 GrazingAlt 入射高度指向

ATK 语法：`Point <Sensor> GrazingAlt <Azimuth> <GrazingAltitude>`（例：`90.0 10000.0`）。语义：**视轴与"离地高度 H 的同心球面"相切**（切球几何），Azimuth 为相对参考方向的水平偏移。

推导（卫星地心距 r_s，切球半径 a = R + H，单位 km）：

　　sin β = a / r_s，β = 视轴与天底方向的夹角　　　　(3.3)

　　δ = 90° − β = 视轴相对本地水平面的下俯角　　　　(3.4)

　　b = (cos ψ·cos δ,  sin ψ·cos δ,  −sin δ)（本地 ENU，ψ 为方位角）　　　　(3.5)

**自检**：直线 S + t·b 到地心 O 的距离恰为 a（附录 A，d = a 精确成立）。直观检验：h = 630 km、H = 10 km 时 β = arcsin(6388/7008) ≈ 65.8°，δ ≈ 24.2°——与 630 km 高度地平线下俯 24.5° 量级一致，即"贴着 10 km 高度的大气层边缘看过去"。入射高度 H 增大 → δ 减小 → 视线更平。

## 3.5 Targeted 目标指向

ATK 语法：`Targeted Tracking <TargetPath> [AboutBoresight] [TrackMode]` 或 `Targeted Fixed <TargetPath> {OrientMethod} <MethodData>`。

- **追踪（Tracking）**：视轴实时指向目标点：

　　b(t) = (P_target(t) − r_sat(t)) / |·|　　　　(3.6)

　　TrackMode（接收/发射/转发）只影响天线增益方向语义，**对几何覆盖判定等价**（都指向目标），本项目不建模天线增益，三种模式结果相同（已在 GUI 实验验证：Targeted+转发与固定追踪得到同一 91.282 s 窗口）。
- **固定指向（Fixed）**：在"指向目标的方向"上再叠加一个固定偏置姿态（与 3.3 的 Fixed 同款方法）。目标方向为基准视轴，偏置旋转后得到最终视轴。

## 3.6 Spinning 旋转扫描

ATK 语法：`Point <Sensor> Spinning <Azimuth> <Elevation> <ConeAngle> {Continuous|Unidirectional|Bidirectional [Start Stop]} <Rate> <Offset>`。参数：旋转轴方向（Az/El，例 `0 -90` = 指向天底）、锥角 ConeAngle（视轴与旋转轴夹角）、扫描模式、转速（°/s）、初始偏差角 Offset。

**本文确定性模型**（修复 ATK 跨实例相位不锚定缺陷）：

　　ŝ = 旋转轴单位方向（由 Az/El 在传感器本地系给出）

　　b₀ = ŝ·cos γ + n·sin γ（n ⊥ ŝ 为 0 相位参考方向）　　　　(3.7)

　　ψ(t) = φ₀ + ω·(t − t₀)（Continuous，φ₀ 锚定分析起点 t₀）　　　　(3.8)

　　b(t) = R(ŝ, ψ(t)) · b₀　　　　(3.9)

其中 R(ŝ, ψ) 为绕 ŝ 转 ψ 的旋转（四元数 (cos ψ/2, ŝ·sin ψ/2)）。**单/双向扫描**：ψ(t) 取三角波（单向为 ψ 从 Start 单调到 Stop 后停住；双向为在 [Start, Stop] 间往返）：

　　p = φ₀ + ω(t − t₀) mod 2L，L = Stop − Start

　　ψ(t) = Start + (p if p ≤ L else 2L − p)　　　　(3.10)

**自检**：任意时刻 |b(t)·ŝ| = cos γ 恒成立（附录 A 逐点验证）；同参数两次运行逐点一致（确定性）。这是相对 ATK 的实质性改进：ATK Spinning 初始相位未初始化（ASLR 绑定），而自研引擎 φ₀ 显式锚定 t₀，结果完全可复现。

## 3.7 External 外部指向文件

ATK 语法：`Point <Sensor> External "<FilePath.sp>"`。格式为 ATK/STK 外部指向文件（时间 + 四元数或欧拉角序列）。自研引擎 P3 实现：解析 .sp → 时间插值（线性/四元数 slerp）→ 逐时刻视轴。**GUI 文档标注 ".pattern 文件等"，格式需在实施时用样例文件确认**。

# 第 4 章　传感器视场模型（Pattern）

## 4.1 通用覆盖判定框架

对时刻 t、目标点 P：计算目标方向 û = (P − r_sat)/|·|，变换到传感器系得 û_s（3.1），再做视场不等式。**输出仍是覆盖窗口**：粗筛 10 s + 边界 1 s 精化（现有 P1 机制不变），仅判定函数替换。圆目标（默认 5 km）保留现有"足印∩目标圆"语义：对复杂视场，用圆心 + 圆周 8 个采样点做模式判定（任一命中即覆盖），多边形目标沿用网格点。

## 4.2 SimpleCone 简单圆锥

　　covered ⇔ û_s·ẑ_s ≥ cos η（即离轴角 θ ≤ η）且 ε ≥ ε_min　　　　(4.1)

对天底指向时 (4.1) 与现有 `λ ≤ λ_max(η, h)` 完全等价（附录 A 自检：θ ≤ η ⇔ λ ≤ λ_max）。

## 4.3 Rectangular 矩形（视锥模型，**注意与直觉差异**）

ATK 参数：垂直半角 V、水平半角 H。**正确模型是相机视锥**，不是"方位角/高度角各自限幅"：

　　covered ⇔ |atan2(û_s·x̂_s, û_s·ẑ_s)| ≤ H　且　|atan2(û_s·ŷ_s, û_s·ẑ_s)| ≤ V　　　　(4.2)

等价形式（z_s > 0 且在视轴前方）：

　　|x_s / z_s| ≤ tan H　且　|y_s / z_s| ≤ tan V　　　　(4.3)

**自检发现**：最初按球坐标 "|az|≤H 且 |el|≤V" 建模是错误的——视轴上 el=90°，任何有限 V 都会把视轴本身排除在外；(4.2) 的视锥形式对视轴、斜对角方向都正确，且保持"SimpleCone(θ) ⊆ Rect(θ,θ)"的内接关系（附录 A 已验证）。ATK 实测 Rect(45,45) 比 SimpleCone45 覆盖更长（74 vs 69 窗口），与矩形面积更大一致。

## 4.4 Conical 复杂圆锥

ATK 参数：内锥半角 θ_in、外锥半角 θ_out、最小/最大钟角 φ_min/φ_max：

　　covered ⇔ θ_in ≤ θ ≤ θ_out　且　φ_min ≤ φ ≤ φ_max　　　　(4.4)

其中 θ = arccos(û_s·ẑ_s) 为离轴角，φ = atan2(û_s·x̂_s, û_s·ŷ_s) 为绕视轴的钟角（从 y_s 参考起算，顺时针；0° 参考待校准）。**退化一致性**：Conical(0, 45, 0, 360) ≡ SimpleCone45（附录 A 2 万方向采样逐点一致；ATK 实测 69/69 窗口一致）。

## 4.5 HalfPower 半功率

ATK 参数：频率 f（GHz）、天线直径 D（m）。抛物面天线半功率波束宽度（HPBW）经验公式（Balanis；Wikipedia Parabolic antenna 亦载 k≈70）：

　　HPBW ≈ 70·λ/D（度），λ = c/f　　　　(4.5)

　　η = HPBW / 2 = 35·λ/D（度）　　　　(4.6)

然后用 SimpleCone(η) 判定（(4.1)）。**自检**：14.5 GHz/1 m → η = 0.72°（ATK 官方默认）；0.5 GHz/0.35 m → η ≈ 60°（实验标称 60° 波束），均吻合。

## 4.6 SAR（合成孔径雷达条带）

ATK 参数（GUI"地面仰角、排除角、是否跟踪父对象高度、高度"；XML `<SAR><MinElevAngle><MaxElevAngle><FwdExclAngle><AftExclAngle><Altitude><TrackParentAlt>`）：

**模型（与 STK `IAgSnSARPattern` 官方定义一致）**：

　　covered ⇔ ε_min_SAR ≤ ε_ground(P) ≤ ε_max_SAR　且　∠(û, v̂_fwd) ≥ ψ_f　且　∠(û, −v̂_fwd) ≥ ψ_a　　　　(4.7)

其中：

- ε_ground(P) = 目标点 P 处观测卫星的仰角（沿用现有几何公式）：

　　tan ε = (cos λ − R/r) / sin λ　　　　(4.8)

其中 λ 为目标点与卫星地心投影的地心角、r 为卫星地心距（推导见 `docs/理论报告.md` 公式 (6)，本报告附录 A 已用 ENU 直接矢量法复核一致）；
- û = 卫星→目标单位方向；v̂_fwd = 沿迹向单位向量（ECI 或 ECF 速度投影到本地水平面）；
- ψ_f/ψ_a = 前/后排除角：目标方向与速度正向/反向的夹角下限（STK 原文："the minimum angle between the forward/aft projection of the velocity vector and the vector to the target"）。

物理含义：**地面仰角带** [ε_min, ε_max] 决定跨迹向条带（近天底 ε 大被 ε_max 排除 → 条带中间有孔洞；远缘 ε 小被 ε_min 排除）；**前后排除角**决定沿迹向长度（排除正前方/正后方，束宽 = 180° − ψ_f − ψ_a，中心在侧视方向）。

**父高度（Altitude/TrackParentAlt）**：STK 语义 = "sensor's parent object altitude（assumed constant）"。ATK rc.5 的跟踪开关不生效（§10.28），项目已用各星 TLE 平均高度近似；自研引擎天然按实际轨道高度逐时刻计算（更正确）。**待校准**：ATK 在"不跟踪父高度"时用固定 Altitude 参与换算的方式（8.3 节 P3 用已记录窗口反推）。

**自检**（附录 A）：550 km 高度、ε∈[12°,70°]、ψ_f=ψ_a=30° 时，近天底点（ε≈78°）被排除、条带中部（ε≈31°）覆盖、远缘（ε≈6°）被排除、前向点（前向角 29°<30°）被排除——四条物理判据全部符合。

## 4.7 幅宽换算（保留现有口径）

幅宽 W（km）仍按 `docs/理论报告.md` 公式 (7)(8) 换算为等效视场半角（逐时刻高度），仅低轨生效，GEO/高轨自动回退视场半角（现有规则不动）。

## 4.8 从判定到覆盖窗口

复用现有两段式：10 s 粗筛检测 → 1 s 边界精化（横跨全程窗口跳过、按连续覆盖段切分内部空隙）；输出/选星 1 分钟片解耦。判定函数替换为 (4.1)-(4.7) 的任意组合（传感器类型 + 指向 + 姿态），窗口合并/裁剪/过滤逻辑不变。

# 第 5 章　约束建模

## 5.1 通用框架

约束是**逐时刻附加判定**：`covered(t) = pattern_ok(t) 且 constraint_ok(t)`（Include 语义）；`ExcludeIntervals` 取反（约束满足的区间被排除）。约束不改变输出形态——ATK 验证报告已确认加约束后仍是同一份覆盖窗口报告。

作用对象分三级（与 ATK GUI/worker 一致）：**目标点（facility）**、**每颗星传感器（sensor）**、**每颗星（satellite）**。同一物理量在不同对象上定义不同（如目标点的仰角 vs 传感器的俯仰角，见 5.2）。

## 5.2 基本约束（12 种）与公式

| 约束 | 对象 | 计算公式 |
| --- | --- | --- |
| AzimuthAngle 方位角 | 目标点/平台 | 目标点：大圆方位角 az = atan2(sin Δλ·cos φ_s, cos φ_t·sin φ_s − sin φ_t·cos φ_s·cos Δλ)，Δλ = λ_s − λ_t（卫星减目标经度）；平台：目标在本地系水平面投影方向角 |
| ElevationAngle 仰角 | 目标点/平台 | 目标点：(4.8) 的 ε；平台：目标在本地系的俯仰角（向下为负） |
| Range 距离 | 任意 | \|r_sat − r_tgt\| |
| AzimuthRate | 任意 | d az/dt（时间栅格中心差分） |
| ElevationRate | 任意 | d ε/dt |
| RangeRate | 任意 | d Range/dt（径向相对速度，与多普勒相关） |
| AngularRate 角变化率 | 任意 | \|d û/dt\|（视线单位向量的变化率） |
| Altitude 高度 | 目标点 | 目标点相对参考球/椭球的高度（地面网格为 0；用户可设） |
| PropagationDelay 传播延时 | 任意 | Range / c |
| LineOfSight 视线 | 任意 | 线段是否被地球遮挡：对地目标等价于 ε ≥ 0；星间用"线段到地心最小距离 ≥ R" |
| fieldofview 视场 | 传感器 | 目标在视场不等式内（与 pattern 判定同源，作为显式开关） |
| TerrainMask 地形 | 目标点 | 需 DEM（后期实现；本期声明为"考虑中"，不生效时按无遮挡） |

变化率类约束统一用中心差分（10 s 粗筛栅格；精化边界附近重新计算），避免解析求导的符号错误，精度对约束判定足够。

## 5.3 光照约束（7 种）

| 约束 | 计算公式 |
| --- | --- |
| SunElevationAngle 太阳仰角 | 太阳方向在对象本地 ENU 系的仰角 |
| SunGroundElevAngle 太阳地平仰角 | 太阳方向在目标点 ENU 的仰角（昼夜判断） |
| LunarElevationAngle 月球仰角 | 月球方向在对象本地 ENU 的仰角 |
| LOSSunExclusion 视线太阳规避角 | ∠(视线方向, ŝ) ≥ 阈值 |
| LOSLunarExclusion 视线月球规避角 | ∠(视线方向, m̂) ≥ 阈值 |
| BSSunExclusion 视轴太阳规避角 | ∠(视轴 b, ŝ) ≥ 阈值（光学传感器避光） |
| BSLunarExclusion 视轴月球规避角 | ∠(视轴 b, m̂) ≥ 阈值 |

太阳/月球方向由 skyfield（生产）或 Meeus 解析（降级）给出（1.3 节）。

## 5.4 实现注意

- 约束区间语义：Min/Max 同时填 = 闭区间；只填一边 = 单侧；AzimuthAngle 必须成对（ATK 要求）；
- ExcludeIntervals/IncludeIntervals 附加选项在窗口后处理实现；
- 约束全部向量化（T 维数组），不引入逐时刻 Python 循环。

# 第 7 章　数值实现要点与性能

## 7.1 数据流

```
每颗星每时刻：
  r_TEME, v_TEME ──(1.1)(1.2)──▶ r_ECEF, v_ECEF
      └──▶ 姿态族 DCM (2.2)-(2.5) ──(+偏移四元数 (2.6))──▶ C_body←ECI
      └──▶ 指向 (第3章) ──▶ 视轴 b(t) ──▶ C_s←ECI
  目标点 P ──▶ û ──(3.1)──▶ û_s ──(4.1)-(4.7)──▶ covered(t)
  约束 (第5章) ──▶ covered_final(t)
  ──▶ 窗口合并（现有两段式）
```

实现上：新模块 `attitude_geometry.py`（姿态族 + 四元数）、`sensor_geometry.py`（指向 + 视场 + 约束）；`coverage_analysis.py` 的 `analyze_one_satellite` 增加配置参数 `attitude_cfg / pointing_cfg / sensor_cfg / constraints`，覆盖判定函数替换，其余不动。

## 7.2 数值稳定性

- 叉积后归一化；投影公式对退化方向防护（分母 < 1e-12 时给出明确异常）；
- arccos 参数 clip 到 [−1, 1]；角度统一用 atan2/度-弧度明确转换；
- 四元数复合后归一化；
- 钟角/方位角 wrap 到 [0°, 360°)；转速连续累计（不重置）保证长时段扫描正确。

## 7.3 性能预算

单星单时刻新增成本：2 次坐标系变换（3×3 矩阵乘）+ 视场不等式（≤ 10 次三角函数）。相对现有"星下点 + haversine + 足印"增加约 1.5～2 倍浮点量。**量级估计**：303 颗 × 8 h × 10 s（2881 步）≈ 870 万次判定，numpy 向量化（T×1 数组）数秒内完成；万颗量级仍 < 60 s（现有 27.6 s 的 2 倍预算内）。约束与姿态不改变复杂度量级（仍是 N×T）。

## 7.4 接口与回归

- CLI/GUI 入口复用现有 `run_atk_windows` 的参数结构（`sensor_type / sensor_params / pointing / constraints / attitude` 已定义在 `atk_ui.py` 的 TOML 持久化），自研引擎读同一配置 → **双引擎同一套配置语义**；
- 回归：`validate_china_remote`、`validate_n2yo_crosscheck`、`validate_sensor_params`、AppTest 全页签。

# 第 10 章　结论与已知边界

## 结论

1. **数学封闭**：姿态族（第 2 章）、指向（第 3 章）、视场（第 4 章）、约束（第 5 章）全部有显式解析公式，可逐时刻计算；
2. **理论已自检**：135 项数值检查全过（8.1），并修正了矩形视锥这一关键口径；
3. **可对拍**：ATK 已有基准数据覆盖全部传感器类型与姿态族（8.3），逐项可验证；
4. **确定性优于 ATK**：Spinning 相位显式锚定分析起点，同参数完全可复现；
5. **不重复造轮子**：轨道外推（SGP4/skyfield）、太阳/月球（skyfield/Meeus）、时间栅格与窗口合并全部复用现有已验证代码。

## 已知边界（如实声明）

- 地形遮挡（TerrainMask）需 DEM，本期不做，默认无遮挡；
- External 指向文件格式（.sp/.pattern）需样例确认后实现；
- SAR 父高度的 ATK 精确换算语义、Fixed matrix 六元素重建、欧拉/YPR 符号、钟角 0° 参考、Spinning 相位参考方向，均列入 3.8 待校准清单，用 ATK 实测反推；
- 姿态动力学（真实卫星的控制律/机动能力约束）不建模——本报告只回答"给定姿态指向，覆盖几何是什么"，不问"卫星能不能转那么快"（后者属调度约束，后续可加角速度/角加速度限制）；
- 目标圆语义：复杂视场用圆心+圆周 8 点采样近似，与现有"足印∩目标圆"的精确重叠比例（circle_overlap_ratio）口径略有差异（5 km 圆边缘效应，ATK 本身也是点判定）。
