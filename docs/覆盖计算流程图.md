# 覆盖计算流程（完整版）

> 从"输入"到"输出"的完整计算链路，配合 `src/coverage_analysis.py` 阅读。

## 流程图

```mermaid
flowchart TD
    IN["输入：地区 GeoJSON、TLE 轨道数据、时间段、参数（视场半角 30°、最小仰角 10°、网格间距 0.2°、时间步长 1 分钟）"]
    IN --> GRID["在地区内撒网格代表点（间距约 22 km）"]
    IN --> PROP["TLE → SGP4 外推（skyfield）→ 卫星每个时刻在惯性系中的位置"]
    PROP --> ROT["考虑地球自转（GMST/UT1 转到地固系）→ 星下点（纬度/经度）＋ 高度 h"]
    ROT --> LAM["对每个网格点：星下点到该点的地心角 λ（haversine 大圆公式）"]
    ROT --> ALT["得到轨道半径 r = R + h（R = 6378.137 km）"]
    IN --> FOV["视场半角 η（默认 30°）"]
    FOV --> LMAX1["覆盖圆边缘仰角 ε0 由 sin η = (R/r)·cos ε0 解出"]
    ALT --> LMAX1
    LMAX1 --> LMAX2["覆盖圆半径角 λ_max = 90° − ε0 − η，且不超过地平线角 acos(R/r)"]
    ALT --> ELE["对每个网格点：仰角 ε = atan2(cos λ − R/r, sin λ)"]
    LAM --> JUDGE{"λ ≤ λ_max 且 ε ≥ 10° ?"}
    LMAX2 --> JUDGE
    ELE --> JUDGE
    JUDGE -- "是" --> P1["该网格点被覆盖"]
    JUDGE -- "否" --> P0["该网格点不被覆盖"]
    P1 --> ANY{"该分钟是否有任一网格点被覆盖 ?"}
    P0 --> ANY
    ANY -- "是" --> MIN1["该分钟：区域被覆盖"]
    ANY -- "否" --> MIN0["该分钟：无覆盖"]
    MIN1 --> WIN["把连续被覆盖的分钟合并成覆盖窗口（两段式：窗口边界用 10 秒精化）"]
    MIN0 --> WIN
    WIN --> OUT["输出：窗口明细 / 卫星汇总（含覆盖率）/ 状态表 / 空窗表 / 文字摘要 / 可用卫星数曲线 / 甘特图 / Excel"]
```

## 三个关键概念在流程中的位置

1. **覆盖圆（足印）**：由 `视场半角 η` 和 `高度 h` 决定（图中 LMAX1/LMAX2 两格）。
   高度越高圆越大；视场角越大圆越大。公式几何推导见 `coverage_analysis.py` 中
   `footprint_max_angle_deg` 的注释。
2. **仰角 ε**：每个网格点看卫星的仰角，由 `地心角 λ` 和 `高度 h` 算出（ELE 一格）。
   `ε ≥ 最小仰角（10°）` 是任务质量门槛；对高轨/大视场，它会把覆盖圆边缘再削掉一圈。
3. **地球自转**：在"星下点"一步处理（ROT 一格）——SGP4 给出的是惯性系位置，
   skyfield 用地球自转（GMST/UT1）转到地固系，网格点随地球转动，所以算出的
   经纬度是"站在地球上看到"的。
