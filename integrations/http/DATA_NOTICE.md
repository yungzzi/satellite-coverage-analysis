# 数据与适用范围

- 城市边界：浙江省及11地市，来源 DataV areas_v3 / 高德2021-05快照；从GCJ-02归一化到WGS84。
  计算采用冻结等面积投影、裁剪网格及真实面积权重；转换方法和源URL见 data/geo/metadata/zhejiang_boundaries.json。
  metadata中 raw_path 是原始快照溯源位置，本精简包仅附运行所需的归一化边界，未附 raw 数据。
- 卫星目录：历史平台110星冻结目录；目录分辨率仅筛选候选，不用于几何推算。
  幅宽及载荷字段并不等于经过任务运营方确认的真实成像能力。
- TLE：三份历史测试快照，用于可重复的几何计算验证；无实时更新、时效拦截或可用影像保证。
- 输出表示固定配置下潜在几何观测机会，不包含云量/天气、真实拍摄排程、采购可得性与传感器行为优化。
  代表点覆盖近似其裁剪网格，5km不是连续区域逐点精确覆盖证明。
- 代码与数据中的来源信息予以保留。本交付不替第三方数据或依赖授予再分发许可；
  面向合作研发交接，不据此宣称全部内容采用统一开源许可证。扩大公开分发或商业使用前由项目方核对授权范围。
